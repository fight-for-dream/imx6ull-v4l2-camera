# 第四阶段：查询摄像头支持的帧率

第三阶段实测：MJPG 640×480 连续采集 100 帧用时 5.15 秒，程序平均接收
19.40 帧/秒。这个数值是实测结果，还需要与摄像头报告的帧率档位比较。

本阶段使用 `VIDIOC_ENUM_FRAMEINTERVALS` 查询 MJPG 640×480 的帧间隔。
例如，间隔为 `1/20 second`，表示摄像头标称每秒 20 帧。
程序只查询能力，不启动采集。

Ubuntu 中进入本目录执行 `make`；把程序传到开发板后运行：

```sh
./v4l2_frame_interval /dev/video1
```

若实际档位包含 20 fps，19.40 fps 与它接近，但还需要结合启动耗时、
调度和缓冲区序号判断原因；不要把一次平均值当成硬件的精确帧率。
