# 第七阶段：摄像头实时预览到 LCD

这是完整摄像头项目的第一条工作链路：

```text
USB 摄像头 → V4L2 取 MJPG 帧 → libjpeg 解码 → framebuffer → LCD
```

程序分成三个容易对照的部分：

- `camera.c`：设置 MJPG 640×480、20 fps，管理 4 个采集缓冲区。
- `display.c`：用系统自带的 libjpeg 逐行解码，按 framebuffer 的 RGB 位偏移写入 LCD。
- `main.c`：反复取帧、显示、还帧；每 100 帧报告显示速率和序号跳跃。

摄像头图像是 640×480，LCD 实测是 1024×600、32 bpp、stride 4096。
首版把画面居中显示，黑边留在四周，不缩放、不修改屏幕分辨率。
程序启动时仍会读取 LCD 的实际参数；如果颜色通道不是每通道 8 位，就报告错误而不猜测格式。

在 Ubuntu 中进入本目录执行 `make`。链接的是交叉工具链 sysroot 中的 `libjpeg.so.8`；
开发板现有根文件系统也提供同版本库。把程序传到开发板后运行：

```sh
./camera_preview /dev/video1 /dev/fb0
```

按 `Ctrl+C` 退出。运行前请先停止其他正在向 `/dev/fb0` 绘图的程序，避免画面互相覆盖。
首版碰到取帧、JPEG 解码或显示错误会清理资源并退出；自动重连和故障恢复放在后续阶段。
