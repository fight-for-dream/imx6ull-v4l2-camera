# 第五阶段：查询当前帧率

第四阶段列出了相机支持的档位：30、25、20、15、10、5 fps。
第三阶段连续采集的实测值是 19.40 fps，但程序没有主动设置帧率。

`VIDIOC_ENUM_FRAMEINTERVALS` 用于列出“可以选择哪些档位”；本阶段使用
`VIDIOC_G_PARM` 查询“设置 MJPG 640×480 后，当前采用哪个档位”。

Ubuntu 中进入本目录执行 `make`；把程序传到开发板后运行：

```sh
./v4l2_current_interval /dev/video1
```

若返回 `1/20 second`，它对应标称 20 fps。实测值 19.40 fps 是从启动采集到
取完 100 帧的平均速率，包含开始等待第一帧的时间，两者不必完全相等。
本程序不会启动视频流，也不会保存图像。
